# Sample Images

Place your test images here for use with the detection examples.

## Recommended Images

For best results with the examples:

1. **Face Detection Examples**: 
   - Images with clear, frontal faces
   - Good lighting conditions
   - Face should be the main subject

2. **Multiple Face Detection**:
   - Group photos
   - Images with 2-5 people
   - Faces should be clearly visible

3. **Eye and Smile Detection**:
   - Close-up portraits
   - High-resolution images
   - Clear facial features

## Image Naming

The examples use `sample.jpg` as the default image name. You can:
- Name your test image as `sample.jpg`
- Or update the image path in the example code
